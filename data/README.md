# Data Directory

This directory will contain the MNIST dataset downloaded automatically when you run the scripts.

The MNIST dataset will be downloaded to `./data/` in the current working directory when you first run either:
- `run_compare_optimizers.sh`
- `run_agm_implementation.sh`

**Note:** The dataset is downloaded automatically by PyTorch's `torchvision.datasets.MNIST` module. No manual download is required.
